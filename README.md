# Modern Calculator

A beautiful, modern, responsive and fully functional calculator built with **HTML, CSS and JavaScript**.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Percentage, square root, square, reciprocal, negate, π, e
- All clear, backspace, decimal support
- Keyboard support (digits, operators, Enter, Backspace, Esc, %, r, s, …)
- Dark / light theme toggle (persisted)
- Animated glassmorphism UI with responsive layout
- Error handling (division by zero, invalid input)
- Repeat-last-operation on repeated `=`

## Run

Just open `index.html` in any modern browser. No build step required.
